# Dataset card: ANES 2024 with synthetic respondents (Study 3, held-out)

Status: design fixed, data not yet built (9 November 2026).

## Purpose

A real survey with a real closed-ended social measurement, contaminated by machine
respondents whose closed answers come from the same language model that writes their open
text. This answers the request for a survey outcome that is not a text statistic.

## Human records

* Source: ANES 2024 Time Series Study, full release (main data file in CSV; "Redacted
  Open-Ends" Excel file), electionstudies.org. Public, no registration.
* Unit: pre-election respondent with a valid value on the outcome and at least one
  non-empty open-ended answer among the eight below.
* Outcomes (closed-ended, scaled to [0, 1]): feeling thermometers for Kamala Harris
  (V241156), Donald Trump (V241157), the Democratic Party (V241166), the Republican Party
  (V241167). ANES missing codes (negative values, and 998/999 if present) are excluded.
* Detector input: the respondent's non-empty answers to the eight like/dislike questions,
  in fixed order, one per line (`d2vi.synthetic.respondent_document`). Candidates:
  V241110, V241112, V241114, V241116 (filters V241109-V241115); parties: V241170, V241172,
  V241174, V241176 (filters V241169-V241175).
* Design variables kept for description only: sample type and interview mode, pre-election
  weight. The estimand of the study is the mean over the human records of the pool (as in
  Studies 1-2), not the weighted ANES population mean.

## Machine records

* Synthetic respondents: persona drawn with replacement from the ANES respondents'
  background variables (age V241458x, sex V241550, race and ethnicity V241501x, education
  V241465x, census region V243007; in the "political" condition also party identification
  V241227x and ideology V241177).
* The model answers the four thermometers and the eight open-ended questions in one JSON
  reply (`d2vi.synthetic.prompt.RespondentPrompt`).
* Generators (open weights, ungated, Colab T4): Qwen2.5-7B-Instruct, OLMo-2-1124-7B-Instruct,
  Phi-3.5-mini-instruct. Conditions: persona {demographic, political} x style
  {plain, human-like}; 400 respondents per model and condition (4,800 in total).
* Sampling: temperature 0.9, top-p 0.95, at most 450 new tokens; one retry with a new seed
  when the reply does not parse; unparsed respondents are reported and excluded.

## Known risks and how they are handled

| Risk | Handling |
|---|---|
| Redaction markers in the human open-ends (names, places) would let a detector separate the two classes trivially | Inspect the Excel file; strip the markers from human text, or apply the same replacement to synthetic text; report the share of affected answers |
| Interviewer-typed answers (face-to-face, video, phone) differ in style from web answers | Report detector operating points by mode; sensitivity analysis on web respondents only |
| Some web respondents in 2024 may already have used a chatbot, so the "human" class is presumed, not verified | Report the detector flag rate by mode (interviewer-administered answers are very unlikely to be machine-written); state the presumption in the paper |
| Persona prompts reproduce stereotypes | Synthetic respondents are used only as contamination; no substantive claim is made from them |
| ANES terms of use | ANES files and human texts are not redistributed; the repository holds code only; synthetic respondents are released on Zenodo |
| Question wording | `ANES2024.wording_checked` is set only after the wording is compared with the 2024 questionnaire |
