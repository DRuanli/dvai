# Dataset card: M4, non-English subsets (held-out)

Status: loader fixed on 10 November 2026 (`d2vi.data.multilingual.load_m4`), files of
github.com/mbzuai-nlp/M4 (`data/`). Features are built by notebook K06 on Kaggle. Before
the loader was fixed only file formats, text lengths and duplicate counts were inspected;
no outcome and no detector was computed.
A software test then ran the pipeline end to end on 600 German documents with a
randomly initialised toy model and a toy tokenizer (the real models cannot be downloaded
on the development machine); its outputs carry no information and were discarded.

* Source: M4 (Wang et al., EACL 2024). Each file holds 3,000 pairs of a human text and a
  machine text written from the same prompt.
* Languages (the domains of this corpus) and generators: Arabic (Wikipedia; ChatGPT),
  Bulgarian (news; ChatGPT, davinci-003), German (Wikipedia; ChatGPT), Indonesian (news;
  ChatGPT), Russian (RuATD; ChatGPT, davinci-003), Urdu (news; ChatGPT). The Chinese subset
  is not used because HC3-Chinese covers Chinese.
* After removing empty and duplicate texts: 42,017 documents (human 2,979-3,044 per
  language; the two generators of Bulgarian and Russian share their human texts).
* Outcomes (addendum A1): multilingual sentiment (`y_sentx`) and lexical diversity
  (`y_ttr`); documents with fewer than 50 XLM-R subword tokens are excluded and counted.
* Detectors (addendum A1): XLM-R trained on 7,500 English M4 documents (Wikipedia and
  Reddit, human and ChatGPT), applied cross-lingually, flag above 0.5; character TF-IDF
  trained per language on the 30% calibration split (human and ChatGPT), so davinci-003 is
  a generator shift.
* Calibration: 30% of the prompts of each language, human and machine texts of a prompt
  together.
* Pools: language x generator x detector (16 non-empty pools).
* Unit for PE1: M4 is one corpus.
