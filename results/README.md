# Result files

Summaries are committed. Raw replication files (`results/raw/`) are not: per-pool
reductions of the held-out runs are in `results/compact/S5`, from which the scripts below
reproduce every held-out summary exactly, and the raw files are regenerated by
`scripts/run_s5.py` (`docs/RELEASE.md`). `results/raw/S5/*/*.manifest.json` record what was
run (code commit, data and protocol hashes, pool sizes, skipped cells).

Held-out results are final as of 13 November 2026. Files marked **post hoc** were defined
after the held-out results had been seen and are descriptive.
